SILENT EVIDENCE — PWA ICONS
===========================

You need to add your app icon in these sizes:

  icon-72x72.png
  icon-96x96.png
  icon-128x128.png
  icon-144x144.png
  icon-152x152.png
  icon-192x192.png   ← most important (Android home screen)
  icon-384x384.png
  icon-512x512.png   ← most important (splash screen)

HOW TO GENERATE ALL SIZES QUICKLY:
1. Go to https://realfavicongenerator.net
2. Upload your logo (at least 512x512 pixels)
3. Download the package
4. Copy all the PNG files into this folder

OR use https://pwabuilder.com — paste your site URL and it generates everything automatically.

TIPS:
- Use a dark red (#dc2626) background with a white skull or "SE" text
- Make it square — phones will round the corners automatically
- PNG format only
